# Atelier Ledger app icon

**The hidden sun behind a ledger sheet**: an ivory disc rising behind an ochre sheet with a black
header band and ruled columns and rows, on a volcanic black field. Three colours, from the Nation's
palette: volcanic black `#141210`, ivory `#efe6d2`, ochre `#d9a441`.

**Tile:** 512 × 512 viewBox, rounded square `rx=112`, as all the Atelier icons. The macOS files add
Apple's 824/1024 margin (`gridcraft-macos-512.png`, `.icns`).

**Provenance:** drawn for Atelier Ledger by hand as SVG (2026). It replaces GridCraft's placeholder
icon. Licence: `LICENSE.txt` (MIT OR Apache-2.0). The file names keep their upstream `gridcraft`
names so packaging stays untouched. The committed renders were made from the same SVG with cairosvg
and Pillow; `packaging/icons.sh` regenerates them.
